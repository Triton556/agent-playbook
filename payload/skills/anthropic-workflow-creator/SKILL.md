# Anthropic Workflow Creator — compatibility entry

Use the single [workflow pilot and metrics procedure](../product-engineering/references/workflow-pilot.md). This entry adds no draft/review/test cycle and does not require loading other creator skills.

For creating or changing a skill, use skill-creator supplied by the selected client (verify availability). For ordinary agent-document editing, use [writing-for-agents](../writing-for-agents/SKILL.md). Select the operation requested; a skill edit is not itself a pilot.

Historical scripts and schemas remain available for existing callers. Read [local mode and provenance](references/codex-local-mode.md) only when using those helpers or inspecting their origins. They are not the default validator, a benchmark engine or instructions to start another agent.
