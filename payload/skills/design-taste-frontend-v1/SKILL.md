# Optional Taste v1 art direction

[Product-ui-design](../product-ui-design/SKILL.md) owns the design method and the chosen visual system. Use Taste for a specific composition, typography or motion question; ordinary UI work need not load it.

Read only the matching section of [recipe notes](references/taste-v1-recipes.md), using its headings to locate the relevant technique. Extract a useful principle and adapt it to the accepted product. Dials and library examples are not defaults; motion, Bento layouts, magnetic buttons and perpetual animation are optional decisions with a purpose.

Preserve existing tokens, icons and components when appropriate. Accessibility, reduced motion, target viewport and frame budget constrain decorative effects. Verify dependencies before using them; selecting a recipe does not require installing its example stack. The existing UI preflight/review supplies acceptance, without a second Taste checklist or full pass.
