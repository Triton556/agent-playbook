# Composition and local adaptations

dev-flow contains only stage routing and the reverse-engineering branch. Each standalone skill owns its instructions, sources, licenses and tools; revisions are pinned in its sources.json.

- dev-plan: Matt Pocock to-spec; material unknowns determine plan scale and questions.
- dev-implement: implement and codebase-design; vertical slices under current permissions.
- dev-verify: tdd and code-review; risk-based behavior tests, current diff, review-only distinct from permission to repair.
- dev-debug: diagnosing-bugs; reproducible signals and hypotheses. Label static analysis honestly when execution is unavailable.
- ui-design: Anthropic frontend-design, an additional Hitbullets Codex adaptation, and gpt-taste for landing pages. Creation, refinement and redesign are equally explicit. Mock Python, mandatory randomness, GSAP, AIDA and a fixed CTA count were removed.
- ui-review: Impeccable toolkit 4.5.2, engine 0.1.14 Windows x64, local context wrapper. Automatic hooks and extra agent definitions are not installed. Actual rendering and behavior outrank an abstract detector count.

The user's current rules replace mandatory upstream interviews, publication, commits and delegation. An accepted brand, accessibility, stack and product requirements outrank a source's aesthetic prohibitions. UI/UX Pro Max and Taste v1 remain separate reference skills. REA remains a candidate in reverse-engineering, not an installed MCP.

Structural validation and Codex discovery establish installation, not the accuracy of model selection or future product quality. Assess those on real tasks.
