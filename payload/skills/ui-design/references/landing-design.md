# Landing and promotional pages

State the audience, offer and primary action using verified content. Reuse the accepted brand; choose layout and typography to make the offer and next step legible at the intended viewport.

Use authentic assets where available; label demonstrations. Do not invent testimonials, results or guarantees. Animation is optional and must not hide content or block the action; honor reduced motion. A static page is valid when it meets the brief.

Verify the primary action, keyboard path, readable content and relevant responsive states in the actual render. Stop after the agreed criteria pass; no second design rehearsal or mandatory library.
