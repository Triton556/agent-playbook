# Versioned construction and defect-specific review

The Gen2 cycle follows concrete Gen1 feedback: animal legs, pristine uniform objects, radial terrain and an unsupported waterfall source. The methods live in the relevant anatomy, organic and built references. The original Gen1 helpers remain available; new helpers generate original geometry rather than importing studied asset cells.

Use `scripts/gen2_recipes.py --model <slug> --seed 153 --output <directory>` or `--category <category>`. Eight categories each have five constructions: nature, architecture, characters, creatures, transport, props, terrain and scenes. These are editable authored examples with bounded variation, not a universal trained generator. Seed determinism and actual geometric diversity are different properties.

Retain seed and construction metadata; align camera/light/framing at declared scale. These examples normalize object height to 1 for shape inspection, not physical-meter claims. Anatomy uses body landmarks rather than horn/gear-inflated bounds.

Review levels separately:

1. File/grid: coordinate bounds, explicit palette, cell/color roundtrip and deterministic writing.
2. Structure: intended connections, cavity samples, declared supports and version preservation.
3. Meaning: limb profiles/gaps, useful openings, cause of wear, branch hierarchy, coast/ridge geometry and anchored flow.
4. Visible result: opposing views, neutral material and appropriate sections at the target view.
5. Delivery: page/assets work after launching; requested editable files are present.
6. Human acceptance: record actual feedback and remaining defects; tests do not supply that judgment.

Declared `gen2_meta` fields are explanatory evidence from each recipe. Their presence alone is not a passing test. External-editor import, rigging, dynamics, collisions and GPU/FPS remain unverified unless the new task actually tests them.

Scene helpers assemble related original assets at role-specific cell-layout scales. Gen2 scenes declare an authored pitch of0.08m/cell for approximate human/building/prop hierarchy; this is a design choice, not measured physical simulation. OBJ vertices remain in cell units: multiply by the declared pitch when importing at meter scale. Standalone source assets retain object-space design grids without a universal meter pitch. Resampling is construction of the kit, not a measured runtime LOD. Keep such choices explicit and select a finer kit grid when the intended camera needs it.

Supply the current project handoff and unknowns.
